# 实验二 · 参考方向决定被报道的孔径增益

> 脚本 `01_code/exp2_metric_recompute.py`；明细 `exp2_metric_recompute.csv`；汇总 `exp2_by_controller.csv`；排序 `exp2_ranking.csv`

## 1. 为什么参考方向会影响"增益"

控制器**不跟踪参考方向**（B1/B2 跟的是瞬时最优 `v_demand`），所以参考方向不改变物理轨迹。
但项目的增益定义是

```
aperture_gain = alignment * coverage
coverage      = span(阵列在参考方向上的投影) / L_ref
```

**coverage 与 misalignment 都是在参考方向上量的**。参考错了，报道的增益就跟着错。
本实验用同一批已存元素轨迹（`trajectory_uav.csv`），只换参考方向重算 —— 纯重分析，不重跑控制器。
