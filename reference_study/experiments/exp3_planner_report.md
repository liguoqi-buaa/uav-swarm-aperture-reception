# 实验三 · 规划型前视 vs 预测型前视

> 脚本 `01_code/exp3_planner.py`；明细 `exp3_planner.csv`；汇总 `exp3_by_controller.csv`

## 1. 为什么新增 B3

把"前视"分成两类：

- **在线预测**（predictive / MPC）：每步短时域预测 + 滚动优化。CEP 版已证在此问题**无益**。
- **离线规划**（planning）：用整窗信息一次性求限速最优参考，再跟踪它。**本实验检验这一路**。

两者都需要未来信息，但性质不同：预测是**在线、局部、受模型误差影响**；规划是**离线、全局、确定**。

## 2. B3 的定义（与 B2 只差一个变量）

B3 与 B2 共享**完全相同的 PD 控制律、限速与响应时延**，唯一差别是跟踪的目标方向：

```
B2 : 目标方向 = v_demand(t)     （瞬时最优，近视）
B3 : 目标方向 = v_plan(t)       （限速最优参考，离线规划）
```

实现上**不重实现任何控制律或动力学**：B2 的目标取自 `geometry["v_demand"]`，所以只需构造一个把 `v_demand` 换成 `v_plan` 的几何副本，再调用项目自身的 `independent_baselines.independent_control` 与 `controllers.step_dynamics`。
