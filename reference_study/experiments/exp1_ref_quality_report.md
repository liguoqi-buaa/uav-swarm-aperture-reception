## 1. 什么是"现有参考"

`scenario_c.rate_limited_directions()` 把参考朝向构造成**以最大角速率朝瞬时最优 `v_demand` 转**的贪心跟随者（不看未来）。本实验把它与**限速最优参考**对比——后者由
`refgenerator.optimal_reference()` 在角度网格上用周期边界 DP 精确求解：

```
max_{theta(0..T)}  sum_t q(theta_t, t)   s.t.  |dtheta|_mod pi <= omega_max * dt
q(theta, t) = sum_m w_m exp(-(L^2/12) cos^2(theta - phi_m) / sigma^2)
```

## 6. 机制

贪心跟随者在饱和时满足 `theta_f(t) = theta_f(0) + omega_max * t`，而最优方向以 `v*(t)` 前进；
当 `|v*| > omega_max` 持续存在时滞后 `(v* - omega_max) * t` **线性累积、无上界**。
滞后绕满半圈后参考方向即变为任意值 —— 这是**结构性失效**，不是调参问题。
速率饱和步占比接近 1 是它的指纹：**每一步都吃满速率 = 永远在追赶**。
