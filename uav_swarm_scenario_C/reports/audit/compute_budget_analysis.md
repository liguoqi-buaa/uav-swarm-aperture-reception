组件含义：`C_gnn_forward` ST-GNN 前向；`C_features` 特征构造；`C_qp_local` 单机 DMPC 的 QP（预测族）；`C_slots` 参考槽位；`C_potential` 复合势场梯度；`C_adjacency` 邻接矩阵；`C_lambda2` λ₂ 特征分解；`C_snr` 链路 SNR；`C_preview_qp` 滚动时域预览 QP。

**注意嵌套关系**：`C_potential ⊃ C_adjacency + C_lambda2 + C_snr`；`C_features ⊃ C_snr`（特征构造内部自己建了一次邻接矩阵）。因此只有**顶层项**可以直接相加：预测族 = `C_features + C_qp_local + C_gnn_forward + C_slots`；参数族的势场路径 = `C_potential`；几何族 = `C_indep_total`。

### 预测控制器的成本归属（关键结论）

| 顶层组件 | ms/step (p50) | 占单步总量 |
|:--|--:|--:|
| `C_features` | 10.221 | 51.2% |
| `C_qp_local` | 5.838 | 29.2% |
| `C_gnn_forward` | 1.517 | 7.6% |
| `C_slots` | 0.268 | 1.3% |
| 其余（python 开销 / 目标轨迹组装 / 限幅） | 2.119 | 10.6% |
| **合计** | **19.962** | **100%** |

→ **单步开销的大头是 numpy 侧的特征构造（10.22 ms，约 51%），神经网络前向只占 1.52 ms（约 7.6%）**。也就是说，预测型控制器相较几何控制器的算力劣势主要来自**实现开销**，而不是来自「学习」本身；即便把这部分优化掉，几何控制器仍然便宜两个数量级。
